This project is a machine-learning-based health assessment tool that predicts possible diseases from user-selected symptoms. Using a Random Forest Classifier, the system evaluates symptom patterns and provides the most likely diagnosis, allowing users to get an early indication before consulting a doctor. The model is trained on a comprehensive medical dataset and can process 50+ symptoms and predict 80+ diseases. achieving an accuracy of ~75%. During development, we used several machine learning and data-processing tools, including Python, NumPy, Pandas, and Scikit-learn.
